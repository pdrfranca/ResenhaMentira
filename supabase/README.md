# Supabase

Esta primeira versão não exige SQL: o jogo usa Realtime Broadcast e Presence diretamente do navegador.

No painel do Supabase, confirme que Realtime está disponível no projeto e use a **Publishable key** no GitHub Actions.

Para salas privadas/anti-invasão em uma versão posterior, podemos trocar os canais públicos por canais privados com autenticação anônima e políticas RLS.
